# 캐치 월드 (번아웃 소각장)

취업 준비생을 위한 3D 힐링 마당입니다. 서류를 태우고, 빨고, 면접을 받아치며 스트레스 지수를 줄입니다.
**학사 과제용 비공식 프로젝트**이며 캐치(Catch)와 무관하고 비상업적 목적으로 제작했습니다.

## 실행

```
npm start        # http://localhost:5173
npm test         # 순수 로직 테스트(node:test)
```

빌드 도구 없이 정적 파일로 동작합니다(Three.js 는 CDN importmap). 배포는 Vercel 에서 Framework 를 **Other**, 빌드 명령 없이 저장소 루트를 그대로 올립니다.

## 구성

- `src/logic/` 화면과 무관한 순수 로직(테스트 포함), `src/` 브라우저 모듈, `assets/` 3D 모델(CC0)과 출처(`assets/CREDITS.md`).
- 설정과 문구(스트레스 지수, 면접 질문 등)는 `src/config.js`에서 고칩니다.
- 방문 통계(Google Analytics 4)는 `GA_MEASUREMENT_ID` 를 넣으면 켜집니다.
- **효과음**: **배경음·앰비언스는 없고 꼭 필요한 곳에만** 효과음을 냅니다(소각로 모닥불의 편안한 타닥임, 사박사박 발소리, 파쇄기, 세탁 덜컹, 면접 질문·확정·반응·팡파르, 팝업 차임 등). 외부 소리 파일 없이 Web Audio API 로 코드에서 합성합니다(`src/audio/`: `recipes.js` 소리 만드는 법, `engine.js` 재생 장치, `sfx.js` 게임이 쓰는 API). 첫 클릭·키 입력 뒤에 켜지고, 우상단 스피커 버튼이나 **M 키**로 끄고 켭니다(저장됨). 소리를 듣고 고치고 싶으면 저장소 루트의 `sounds.html`(`npm start` 후 `http://localhost:5173/sounds.html`)에서 모든 소리를 하나씩·한꺼번에 재생하고 볼륨을 조절하며 자동 점검 표를 볼 수 있습니다(게임은 불러오지 않습니다).
- **멀티플레이 전송량과 발표 당일 비상 조치**: 같은 공간의 방문자는 방(정원 `MULTIPLAYER.roomCap`, 현재 4명)으로 나뉘고, 위치는 시계로 보내지 않고 **움직임이 바뀔 때만**(걷기 시작·멈춤·방향 꺾임·속도 변화·옷·앉기·공간 이동) + 느린 보정(서 있으면 10초, 걸으면 4초마다)으로 보냅니다. 받는 쪽은 마지막 위치+속도로 이어 그립니다(`src/logic/netMotion.js`). 무료 요금제 한도(초당 약 100 메시지)와 계산식은 `src/config.js` 의 `MULTIPLAYER` 주석과 `src/logic/netBudget.js` 에 있습니다(어림: 초당 전달 ≈ 인원 × (방 정원 - 1) × 한 사람이 초당 보내는 수). **발표 당일 비상 조치: `config.js` 의 `MULTIPLAYER.enabled` 를 `false` 로 올리면(배포) 모든 방문자의 멀티플레이가 즉시 꺼집니다(게임은 정상).** 일부만 줄이려면 `roomCap`(방 정원)을 낮추거나 `sustainedHz`(사람당 평균 전송 상한)를 낮춥니다. 시험용 주소 옵션: `?mp=off`(이 탭만 끔), `?mp=local`(같은 브라우저 탭끼리만), `?mpdev=<태그>`(시험 채널), `?mpcap=N`(이 탭의 방 정원).
