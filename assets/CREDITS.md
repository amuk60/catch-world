# 에셋 출처

모든 3D 모델은 **Kenney (www.kenney.nl)** 의 무료 에셋이며 라이선스는 **CC0 (Creative Commons Zero, 퍼블릭 도메인)** 입니다. 출처 표기는 의무가 아니지만 감사의 뜻으로 적습니다. 각 팩의 `License.txt`는 폴더에 그대로 보존합니다.

| 폴더 | 팩 이름(버전) | 용도 | 라이선스 |
|---|---|---|---|
| `models/kenney-mini-characters/` | Mini Characters (2.0) | 주인공 캐릭터 | CC0 |
| `models/kenney_nature-kit/` | Nature Kit (2.1) | 나무(단풍 포함), 돌길, 연못, 풀·꽃, 바위, 모닥불(소각로) | CC0 |
| `models/kenney_fantasy-town-kit_2.0/` | Fantasy Town Kit (2.0) | 등롱, 울타리, 아치문, 석재 기둥, 분수 | CC0 |
| `models/kenney_furniture-kit/` | Furniture Kit (2.0) | 소품(벤치·책상·조명 등, 필요 시) | CC0 |
| `models/kenney_building-kit/` | Building Kit (1.0) | 현재 미사용(보유). 단계 8d 건물 외관 검토 결과 중세풍 석재 조각이라 회사 빌딩에 맞지 않아 쓰지 않았다 | CC0 |

| 파일 | 출처 | 비고 |
|---|---|---|
| `catch_logo.png` | 팀 제작 | 캐치 브랜드 요소. 비공식 학사 과제용으로만 사용. 파일은 보관하지만 현재는 사용하지 않음 |

- **효과음(배경음·앰비언스 없음)**: 모든 소리는 Web Audio API 로 코드에서 합성합니다(`src/audio/recipes.js`, 모닥불은 `src/audio/fireSynth.js`). 외부 오디오 에셋(녹음·샘플·음악 파일)을 쓰지 않으므로 별도의 출처 표기나 라이선스가 필요 없습니다.
- 사용하지 않는 형식(FBX, OBJ, DAE, STL)과 미리보기 이미지는 용량 때문에 삭제했습니다. 필요하면 kenney.nl에서 다시 받을 수 있습니다.
- `assets/reference/`(디자인 레퍼런스 영상·스크린샷)는 저작권이 팀에 없으므로 **저장소에 올리지 않습니다**(`.gitignore`).
