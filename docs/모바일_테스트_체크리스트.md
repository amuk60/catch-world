# 모바일 테스트 체크리스트 (아이폰 + 크롬 앱 기준)

실제 아이폰으로는 개발 중에 시험하지 못했습니다(컴퓨터의 크롬 모바일 흉내로만 확인). 아래 순서대로 한 번 눌러 보고, 안 되는 항목을 알려 주세요.
각 항목은 **"이렇게 해 보세요 → 이렇게 되어야 해요"** 입니다.

## 0. 준비

- 배포 주소를 아이폰 크롬 앱으로 엽니다. (같은 와이파이에서 개발 서버로 시험할 때는 `http://<컴퓨터 IP>:5366/` — 컴퓨터 IP 는 `ipconfig` 의 IPv4 주소)
- 아이폰 **무음 스위치(옆 버튼)를 꺼 두세요.** 무음 모드에서는 웹 소리가 나지 않습니다(아이폰 정책).
- 화면 자동 회전 잠금을 풀어 두세요(제어 센터의 자물쇠 아이콘).
- 처음부터 다시 보고 싶으면 크롬 시크릿 탭으로 여세요(튜토리얼·닉네임이 처음처럼 나옵니다).

## 1. 첫 화면

1. 세로로 든 채 주소를 연다 → 바로 플레이 화면이 나와야 해요(회전 안내 없음). 게임 화면이 화면을 꽉 채우고(아래·옆 흰 띠, 스크롤 없음), 캐릭터는 화면 아래쪽 가운데, 그 앞(위쪽)으로 마당이 보여요.
2. 세로 화면 위쪽 → 맨 위 한 줄에 스트레스 막대(폭 전체), 그 아래 줄 왼쪽에 "오늘의 힐링 코스"(접힌 알약), 오른쪽에 ⋯ 메뉴·스피커, 그 아래 왼쪽에 작은 접속 칩. 서로 겹치지 않고 노치·다이내믹 아일랜드에 가리지 않아야 해요.
3. 세로 화면 아래쪽 → 왼쪽 아래 조이스틱, 오른쪽 아래 E 버튼(가까이 가면), 그 위에 행동 버튼(태우기·자동 등). 버튼이 화면 밖으로 넘치거나 조이스틱과 겹치지 않고, 아래 홈 막대에 가리지 않아야 해요.
4. 폰을 가로로 돌린다 → 바로 가로 배치(예전과 같은 모습)로 바뀌고 화면이 찌그러지거나 잘리지 않아야 해요. 다시 세로로 → 세로 배치로. **조이스틱을 누르고 있거나 화면을 끄는 도중에 돌려도** 캐릭터가 혼자 계속 걷거나 카메라가 튀지 않아야 해요(손을 뗐다 다시 잡으면 정상).
5. 노치(카메라 구멍) 쪽으로 가로로 돌려도 → 조이스틱·버튼이 노치나 아래 홈 막대에 가리지 않아야 해요.
5-1. 세로에서 주소창이 보였다 숨었다 할 때(화면을 살짝 끌면) → 화면이 늘었다 줄어도 캐릭터가 찌그러지지 않고 버튼 위치가 따라와야 해요.
5. 닉네임 카드가 뜨면 입력칸을 누른다 → 키보드가 올라오고, 화면이 확대되지 않으며, 입력칸과 "이 이름으로 시작" 버튼이 키보드 위에 보여야 해요. "나중에 정하기"도 눌러져야 해요.
6. 소개 카드의 "시작하기"/"건너뛰기" → 눌러져야 해요(카드가 화면 안에 다 보이거나, 안에서 스크롤돼요).

## 2. 이동·카메라

7. 왼쪽 아래 동그란 조이스틱을 엄지로 끈다 → 끈 방향(화면 기준)으로 캐릭터가 걷고, 살짝 끌면 천천히, 끝까지 끌면 빨리 걸어요. 손을 떼면 바로 멈춰요.
8. 바닥을 톡 누른다 → 그 자리로 걸어가고 바닥에 표시가 떠요. 조이스틱을 잡으면 그 걸어가기는 취소돼요.
9. 빈 화면을 한 손가락으로 끈다 → 카메라가 캐릭터 둘레로 돌아요(톡 누를 때는 돌지 않아요).
10. 두 손가락으로 벌리기/오므리기 → 가까워지고/멀어져요(너무 가깝거나 멀리는 안 가요). 페이지 자체가 확대되면 안 돼요.
11. 조이스틱을 왼손으로 잡은 채 오른손으로 화면을 끈다 → 걸으면서 동시에 카메라가 돌아야 해요.
12. 화면을 아래로 당긴다 / 두 번 톡톡 / 길게 누른다 → 새로고침, 확대, 글자 선택·돋보기·메뉴가 생기면 안 돼요.

## 3. 버튼(오른쪽 아래)

13. 모닥불 근처 통나무로 간다 → 오른쪽 아래에 주황색 **E 버튼 "앉기"** 가 떠요. 누르면 앉아요. 앉으면 E 버튼이 "일어나기", 그 위에 **V "불멍 시점"** 버튼, 그 위에 "마시멜로 굽기" 버튼이 보여요.
14. V "불멍 시점" → 1인칭 불멍 시점, 다시 누르면("원래 시점") 돌아와요.
15. "마시멜로 굽기" → 1인칭으로 굽기 시작. "누르고 돌리기"를 누르고 있는 동안(또는 화면을 누르고 있는 동안) 마시멜로가 돌고, 떼면 멈춰요. "꺼내기"로 끝나요. 오른쪽 아래 "취소"도 눌러져요.
16. 모닥불 바로 앞에 선다 → 오른쪽 아래 "태우기"·"자동" 버튼. "태우기" → 물건 고르기 창이 뜨고, 그림을 누르면 태워요. "취소"로 닫혀요. "자동"은 켜지면 주황색.
17. 파쇄기·세탁소(세탁·널기, 빨 것 고르기)도 같은 식으로 버튼으로 돼요.
18. 포춘쿠키 상점 앞 → E "포춘쿠키 고르기" → 쿠키를 눌러 고르고, 쿠키를 빠르게 톡톡 눌러 깨요. 오른쪽 위 ✕ 로 언제든 닫혀요. 운세 종이의 버튼(캐치 열기·한 개 더)이 눌러져요.
19. 소원 조각상 앞 → E "소원 빌기" → 소원 카드가 뜨고 **키보드가 바로 올라와야 해요**(안 올라오면 입력칸을 한 번 눌러 보세요 → 그때는 올라와야 해요). 키보드 위로 입력칸·"소원 빌기" 버튼이 보여야 해요. "취소"로 닫혀요.
20. 면접장 문 앞 → E "들어가기" → 면접장으로 이동. 의자에서 E "앉기" → 오른쪽 아래 면접 버튼 → 아래쪽 답변 창의 답을 눌러 고를 수 있어요. "다음에 할게요"로 닫혀요.
21. 세탁소에서 새 셔츠 입기, 나가기 문도 E 버튼으로 돼요.

## 4. 메뉴·안내

22. 오른쪽 위 **⋯** → 메뉴: 불멍 시점 / 인사·응원말 / 소리 켜기·끄기 / 조작 안내 / 튜토리얼 다시 보기, 맨 아래 비공식 표기. 메뉴 밖을 누르면 닫혀요.
23. "인사·응원말" → 말 목록이 뜨고, 누르면 내 머리 위 말풍선.
24. "조작 안내" → 터치용 안내(조이스틱·E 버튼·끌기/두 손가락) 카드. × 로 닫혀요.
25. 왼쪽 위 "오늘의 힐링 코스" → 처음엔 접혀 있고, 누르면 펼쳐져요(길면 안에서 스크롤). 항목을 누르면 가는 방향 화살표.
26. 스트레스 지수가 20 아래·0 이 되면 → 오른쪽 팝업·가운데 결과 카드가 화면 안에 다 보이고 버튼(캐치 열기·공유·계속 둘러보기·다시 하기·✕)이 눌러져요.

## 4-1. 세로 화면에서 다시 확인

아래는 세로로 든 채 확인해 주세요(가로에서 되는 것은 세로에서도 똑같이 돼야 해요).

S1. 조이스틱·한 손가락 끌기(회전)·두 손가락(확대·축소)·바닥 톡(이동) → 가로와 똑같이 돼요. 캐릭터 둘레의 통나무·모닥불이 양옆으로 너무 잘리지 않아야 해요.
S2. 모닥불 앞 → 오른쪽 아래 E 버튼 위에 "태우기·자동"이 보여요. 통나무에 앉으면 E "일어나기", 그 위 V "불멍 시점", 그 위 "마시멜로 굽기"가 한 줄씩 쌓여 화면 밖으로 넘치지 않아야 해요.
S3. 태울 물건 고르기·세탁소 빨 것 고르기 → 아래쪽 창에 그림이 3개씩 두 줄로 보이고 "취소"가 눌러져요.
S4. 소원 조각상 E → 소원 카드가 화면 폭에 맞게 뜨고, **키보드가 올라와도 입력칸과 "소원 빌기" 버튼이 키보드 위에 보여야 해요.** 닉네임 카드(처음 화면)도 마찬가지.
S5. 포춘쿠키 → 쿠키 고르기·깨기·운세 종이가 화면 안에 다 보이고 오른쪽 위 ✕ 가 눌러져요.
S6. 면접장 → 의자에 앉아 면접을 시작하면 아래쪽에 질문과 답 버튼 3개가 세로로 쌓여 보이고, 그 위로 면접관 말풍선·내 캐릭터가 보여야 해요(답 창에 가리지 않게 화면이 살짝 위로 올라가요). 답을 누르면 말풍선이 화면 안에 보여요.
S7. 세탁소·면접장 안 → 방이 화면 가운데에 보이고 손가락으로 돌려 구석까지 볼 수 있어요.
S8. 스트레스가 목표 아래로 내려가면 → 아래쪽에서 올라오는 팝업(세로에서는 아래 시트), 0 이 되면 가운데 결과 카드. 글자가 읽히고 버튼이 다 눌러져요.
S9. 왼쪽 위 힐링 코스를 펼친다 → 목록이 ⋯ 메뉴를 가리지 않고, 길면 안에서 스크롤돼요. ⋯ 메뉴·인사·응원말 목록도 화면 안에 다 보여요.
S10. 불멍 중 안내 글·튜토리얼 안내 글 → 위쪽 접속 칩 아래에 작게 보이고 터치용 문구(조이스틱·버튼)로 나와요.

## 5. 소리·안정성

27. 첫 터치 뒤 → 모닥불 소리·발소리·효과음이 나요(무음 스위치 꺼짐 상태에서). 오른쪽 위 스피커 버튼으로 끄고 켜져요.
28. 홈으로 나갔다 돌아온다 / 다른 앱 갔다 온다 → 소리가 멈췄다가, 화면을 한 번 누르면 다시 나와요. 조이스틱이 혼자 움직이지 않아요.
29. 5분 정도 돌아다닌다 → 폰이 아주 뜨거워지거나 화면이 하얗게 바뀌거나(그래픽 끊김) 새로고침되지 않아야 해요.
30. 다른 사람(PC)과 같은 방 → 서로 보이고 인사말이 보여요(아래 가운데 접속 칩: "접속 중 N명").

## 알려진 한계

- 세로·가로 모두 플레이할 수 있어요. 세로는 가로 폭이 좁아서 카메라를 조금 멀리 두고 캐릭터를 화면 아래쪽에 둬요(양옆은 가로보다 덜 보여요: 손가락으로 돌려 보세요). 보정 값은 `src/config.js` 의 `MOBILE.portrait`.
- 키보드가 올라온 동안에는 화면 높이가 줄어도 세로/가로 배치를 바꾸지 않아요(입력 중 배치가 뒤집히지 않게).
- 아이폰 **무음 모드에서는 소리가 나지 않아요**(웹 소리 정책). 첫 터치 전에는 소리가 나지 않아요.
- 실제 아이폰에서 직접 시험하지 못했어요. 특히 ① 소원 카드에서 키보드가 저절로 올라오는지, ② 키보드가 올라온 뒤 카드 위치, ③ 주소창이 보였다 숨을 때 화면 높이는 기기마다 다를 수 있어요.
- 저사양 설정(그림자 맵 작게, 픽셀 비율 1.5, 가로등 점광 2개)이라 PC 보다 화질이 조금 낮아요. 오래된 폰에서는 끊길 수 있어요(설정은 `src/config.js` 의 `MOBILE`).
- 조이스틱 세기에 따라 걷는 속도는 바뀌지만 걷기 동작 속도는 그대로예요(살짝 밀면 미끄러지듯 보일 수 있어요).
- 포춘쿠키 깨기는 빠르게 여러 번 눌러야 해요(멈추면 다시 단단해짐 — PC 와 같은 규칙).
- 마우스 올리면 뜨던 이름표(툴팁)는 터치에서는 없어요.
- 개발·데스크톱에서 모바일 화면 확인: 주소 뒤에 `?mobile=1`(강제 켜기), 휴대폰에서 PC 화면 보기: `?mobile=0`.
